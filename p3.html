P3: Feature-Branch Git Workflow

Practical 3 · Developing a feature on a separate branch

1) Prepare the Project

Go to the project folder and check the current branch.

cd ~/dev-projects/bosscoder-module1
git branch

If the repository already has a remote named origin and a main branch, update it before starting:

git checkout main
git pull

2) Create a Feature Branch

Create a new branch for the About page and confirm that it exists.

git checkout -b feature/add-about
git branch

3) Create and Commit the Feature

Create the file, add a heading, and review the changes.

touch docs/about.md
echo "About this portfolio" > docs/about.md
git status
git add docs/about.md
git commit -m "Add about page"

4) Merge into Main and Push

Switch back to the main branch, merge the feature branch, and push the updated main branch to GitHub.

git checkout main
git merge feature/add-about
git push

After the merge is complete, delete the local feature branch.

git branch -d feature/add-about

Important: git pull and git push require a remote connection. If origin is not configured, connect the project to its GitHub repository first.

Workflow at a Glance

main → create feature branch → make changes → commit → merge into main → push to GitHub → delete feature branch.

What I Learned

I learned how to create and switch branches, make a feature-specific commit, merge the feature into the main branch, push changes, and remove a completed branch.
