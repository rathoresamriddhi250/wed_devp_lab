P2: PORTFOLIO REPOSITORY WITH INITIAL COMMIT

1. Check Git installation
git --version

If Git is not installed, download it from:
https://git-scm.com/

2. Configure your Git identity
Use your own name and email address:

git config --global user.name "Samriddhi"
git config --global user.email "your-email@example.com"

3. Go to your project folder
cd ~/dev-projects/bosscoder-module1

4. Initialize the Git repository
git init
git status

5. Add placeholder files to the folders
touch docs/.gitkeep src/.gitkeep notes/.gitkeep

6. Stage and commit the project structure
git add .
git commit -m "Initial commit: project structure"

7. Verify the commit
git log --oneline

Expected result:
Git is initialized in the project folder, and the initial project structure is saved in the first commit.
