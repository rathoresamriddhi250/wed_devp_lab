P1: Project Folder and Terminal Navigation

Practical 1 · Working with folders and files using the terminal

i) Open the Terminal

On a Mac, press Command + Space, type Terminal, and press Enter. On Windows, open Command Prompt or PowerShell.

ii) Basic Navigation Commands

Use these commands to check your location, move between folders, and manage files.

  • pwd — show the current folder path.
  • ls — list files and folders (dir in Windows CMD/PowerShell).
  • cd folder — enter a folder.
  • cd .. — move up one folder.
  • cd ~ — go to the home folder.
  • mkdir — create a folder.
  • touch file.txt — create an empty file (Mac/Linux).
  • rm file.txt — delete a file.
  • rm -r folder — delete a folder and its contents.
  • clear — clear the terminal screen.

Careful: rm permanently removes items from the command line. Check the file or folder name before running it.

iii) Exercise: Build the Project Structure

Run the following commands one by one to create a project folder with three subfolders and a README file.

cd ~
mkdir -p dev-projects/bosscoder-module1
cd dev-projects/bosscoder-module1
pwd
mkdir docs src notes
touch README.md
ls

Expected folder structure

bosscoder-module1/
├── docs/
├── src/
├── notes/
└── README.md
