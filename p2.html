P2: Portfolio Repo with an Initial Commit

Practical 2 · Starting version control with Git

1) Initial Setup

Check whether Git is installed on your Mac. If the command is not found, install Git from git-scm.com.

git --version

Set the name and email that Git should attach to your commits. Replace the sample email with the email you use for GitHub.

git config --global user.name "Samriddhi"
git config --global user.email "your-email@example.com"

2) Create the Initial Commit

Move into the project folder, initialize Git, and check the repository status.

cd ~/dev-projects/bosscoder-module1
git init
git status

Add placeholder files so Git can track the empty folders. Git does not track empty folders by themselves.

touch docs/.gitkeep src/.gitkeep notes/.gitkeep
git add .
git commit -m "Initial commit: project structure"
git log --oneline

Command Summary

  • git init creates a Git repository in the current folder.
  • git status shows changed and untracked files.
  • git add . stages the project files.
  • git commit saves a snapshot in the repository history.
  • git log --oneline displays a compact commit history.

Note: Run these commands inside the project folder. The initial commit is stored locally until a remote repository is connected and the branch is pushed.

What I Learned

I learned how to check and configure Git, initialize a repository, stage files, create the first commit, and view the commit history.
